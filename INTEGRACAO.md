# Integração

## Imagens
Copiar `public/principios/` e `public/principios.css`.

No `<head>` da página do projeto, acrescentar:

```html
<link rel="stylesheet" href="/principios.css?v=1">
```

As classes necessárias são:

- `transparency`
- `pasture`
- `welfare`
- `community`
- `seasonality`
- `soil`

Exemplo:

```html
<div class="principle-visual transparency"></div>
```

## Legal
Substituir:

- `public/privacidade.html`
- `public/termos.html`

Copiar também `public/legal.css`.

## Antes de publicar
Completar o nome fiscal, NIF profissional, morada profissional e entidade RAL aplicável. Não publicar com esses avisos pendentes.
